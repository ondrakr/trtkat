Public assets folder for static files.

Recommended structure:
- logo/         -> brand logos (svg, png, webp)
- images/       -> page images/photos/backgrounds
- icons/        -> small UI icons and favicons

How to use in React:
- /logo/logo.svg
- /images/hero.webp
- /icons/favicon.ico

Example:
<img src="/images/hero.webp" alt="Hero image" />
